# Predicting Online Shopper Purchase Intention

## Overview

This project builds a machine learning model to predict whether an online shopper will make a purchase based on session behavior.

## Models Used

* Logistic Regression
* Random Forest

## Techniques

* Feature Engineering
* Threshold Tuning
* Feature Importance
* ROC Curve Analysis

## Key Findings

* PageValues is the strongest predictor
* High engagement increases purchase probability
* High bounce rate decreases conversions

## Business Impact

The model can help e-commerce businesses identify high-intent users and improve conversion rates.

## Technologies

Python, Pandas, Scikit-learn, Matplotlib, Seaborn
